# TommyTweaker

A powerful system tweaking utility for Windows, built with Tauri and Svelte.

## Features
- CPU & GPU Optimization
- Network Tweaks (MSI Mode, TCP Optimization)
- Storage & Filesystem Management
- Input Latency Reduction
- System & Gaming Optimizations

## Tech Stack
- **Frontend**: Svelte, TypeScript
- **Backend**: Rust (Tauri)
- **Styling**: CSS (Inter font, custom design system)

## Development

```bash
npm install
npm run tauri dev
```
