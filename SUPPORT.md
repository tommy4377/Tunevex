# Support

For bug reports, include the Tunevex version, Windows version/build, the exact tweak or tool involved, reproduction steps, expected behavior, actual behavior, and whether the operation was Apply, Undo, Import, or a one-shot action.

Attach only sanitized logs or screenshots when they materially help reproduce the issue. Never include API keys, tokens, credentials, private paths, or unrelated system information.

For feature requests, describe the Windows setting or workflow you want supported, the intended benefit, and any known rollback or compatibility concerns.
