# Security Policy

Security fixes target the latest Tunevex release.

Tunevex is an elevated Windows utility. Reports involving privilege boundaries, command execution, profile validation, credential storage, registry writes, rollback behavior, destructive operations, or untrusted input are especially important.

Please use GitHub private vulnerability reporting when available. Do not place exploit details, credentials, API keys, private logs, usernames, device identifiers, or other sensitive machine information in a public issue.

When sharing diagnostics, sanitize paths and logs first.
